# @pixling/pi-proxy

Talk with [pi](https://github.com/earendil-works/pi) through a
[Pixling](https://pixling.app) resident on your Mac desktop: replies show on it,
and what you type there goes back to pi, even when it is idle.

```sh
pi install npm:@pixling/pi-proxy
```

Requires Pixling with **CLI connection** on and `pixling` on your PATH.
Experimental.

More: https://github.com/pixling/agent-kit
