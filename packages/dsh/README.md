# @pixling/dsh-proxy

Talk with DeepSeek Harness (dsh) through a [Pixling](https://pixling.app)
resident on your Mac desktop: replies show on it, permission requests become
questions on it, and what you type there reaches the session, even when it is idle.

```sh
dsh plugin --profile web add @pixling/dsh-proxy
```

For the Web UI and the Desktop app. Restart the profile after adding it.

Requires Pixling with **CLI connection** on and `pixling` on your PATH.
Experimental: dsh is in developer preview and its plugin API may change.

More: https://github.com/pixling/agent-kit
